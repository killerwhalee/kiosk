# 후원자 일일 찻집 주문 시스템

직원이 태블릿으로 주문을 입력하면, 각 주방 담당 서빙 직원 화면에 주문이 바로 뜹니다.
서빙 직원은 화면을 보고 주방에 필요한 수량을 요청하고, 음식을 테이블에 가져다준 뒤 완료 처리합니다.

```
[주문 입력 태블릿] ──▶ [센터 서버] ──▶ [1번 주방 서빙 직원 화면]  불고기
                                   └─▶ [2번 주방 서빙 직원 화면]  라자냐
                                   └─▶ [관리자 화면]  품절·취소·매출
```

## 화면

| 주소 | 누가 | 하는 일 |
|---|---|---|
| `/order` | 주문받는 직원 (세로 태블릿) | 테이블 선택 → 메뉴·수량 → 확인 → 전송 |
| `/station/1` | 1번 주방 서빙 직원 | 불고기 주문 확인, 주방 요청, 서빙 완료 |
| `/station/2` | 2번 주방 서빙 직원 | 라자냐 주문 확인, 주방 요청, 서빙 완료 |
| `/admin` | 운영 책임자 | 매출·판매 수량, 품절 처리, 주문 취소, 초기화 |
| `/` | 누구나 | 위 화면들로 가는 시작 페이지 |

### 서빙 직원 화면 사용법

1. 처음 열면 **시작하기**를 누릅니다. 알림음을 켜기 위해 필요합니다.
2. 새 주문이 오면 **대기** 칸에 주문표가 생기고 화면 테두리가 깜빡입니다.
   대기 주문이 하나라도 남아 있으면 **주방에 요청할 때까지 3초마다 알림음이 계속 울립니다.**
3. 맨 위의 **"주방에 요청할 수량"**(예: `불고기 5개`)을 요리 담당에게 말한 뒤 **모두 주방에 요청**을 누릅니다.
   한 건씩 처리하려면 주문표마다 있는 **주방 요청** 버튼을 누릅니다.
4. 음식이 나오면 테이블 번호를 보고 가져다준 다음 **서빙 완료**를 누릅니다.
5. 잘못 눌렀으면 되돌리기(↶) 버튼으로 이전 단계로 되돌립니다. 서빙 완료 목록은 접혀 있습니다.

주문 후 10분이 지나도 서빙되지 않은 주문은 경과 시간이 빨간색으로 표시됩니다.

## 설치 및 실행 (센터 서버)

필요한 것은 **Node.js 18 이상**뿐입니다. 외부 패키지를 쓰지 않아서 `npm install`이 필요 없습니다.

```bash
git clone https://github.com/killerwhalee/kiosk.git
cd kiosk
npm start
```

실행하면 접속 주소가 화면에 출력됩니다.

```
후원자 일일 찻집 주문 시스템이 시작되었습니다.
  이 컴퓨터에서: http://localhost:3000
  tailscale0   http://100.x.y.z:3000
  ...
```

### 옵션 (환경 변수)

| 변수 | 기본값 | 설명 |
|---|---|---|
| `PORT` | `3000` | 서버 포트 |
| `ADMIN_PIN` | 없음 | 설정하면 관리자 기능(품절·취소·초기화)에 PIN이 필요합니다 |
| `KIOSK_DATA` | `data/state.json` | 주문 저장 파일 위치 |
| `KIOSK_CONFIG` | `config.json` | 설정 파일 위치 |

```bash
ADMIN_PIN=1234 npm start            # macOS / Linux
set ADMIN_PIN=1234 && npm start     # Windows (cmd)
```

## 태블릿 접속 (Tailscale)

서버에 Tailscale이 설치되어 있으므로, 태블릿에도 Tailscale 앱을 설치하고 **같은 계정(tailnet)으로 로그인**하면 어디서든 접속할 수 있습니다.

- MagicDNS를 쓰는 경우: `http://<서버 컴퓨터 이름>:3000/order`
- IP를 쓰는 경우: `http://100.x.y.z:3000/order` (서버 실행 시 출력되는 `tailscale0` 주소)

태블릿과 서버가 같은 와이파이에 있다면 Tailscale 없이 서버의 내부 IP(`192.168.x.x`)로 접속해도 됩니다.

### (권장) HTTPS 주소 만들기

브라우저는 HTTPS에서만 "화면 꺼짐 방지" 기능을 허용합니다. 서버에서 아래 명령을 한 번 실행하면 Tailscale이 HTTPS 주소를 만들어 줍니다.

```bash
tailscale serve --bg 3000
```

이후에는 `https://<서버 이름>.<tailnet 이름>.ts.net/station/1` 처럼 접속합니다.
그래도 각 태블릿의 **화면 자동 꺼짐은 "안 함"으로 설정해 두는 것을 권장합니다.**

## 메뉴·테이블 바꾸기

`config.json`을 수정하고 서버를 다시 시작하면 됩니다.

```json
{
  "title": "후원자 일일 찻집",
  "port": 3000,
  "tables": 11,
  "stations": [
    { "id": 1, "name": "1번 주방" },
    { "id": 2, "name": "2번 주방" }
  ],
  "menus": [
    { "id": "bulgogi", "name": "불고기", "price": 10000, "station": 1 },
    { "id": "lasagna", "name": "라자냐", "price": 10000, "station": 2 }
  ]
}
```

- 메뉴를 추가하려면 `menus`에 한 줄을 넣고, `station`에 만드는 주방 번호를 적습니다. `id`는 영문으로 씁니다.
- 운영 중에는 메뉴 `id`를 바꾸지 마세요. 이미 들어온 주문과 연결이 끊어집니다.

## 당일 운영 체크리스트

- [ ] 서버에서 `npm start` 실행 (터미널 창은 닫지 않기)
- [ ] 주문 태블릿에서 `/order`, 서빙 직원 기기에서 `/station/1`, `/station/2` 열기
- [ ] 서빙 직원 화면에서 **시작하기**를 누르고 알림음 소리 확인
- [ ] 리허설 주문을 넣어 양쪽 주방 화면에 뜨는지 확인
- [ ] 관리자 화면에서 **전체 주문 초기화**로 리허설 주문 지우기
- [ ] 태블릿 화면 자동 꺼짐 끄기, 충전기 연결

## 문제가 생기면

| 증상 | 대처 |
|---|---|
| 화면 위 연결 표시 옆 숫자(예: `연결됨 · 35ms`) | 서버까지 왕복 지연 시간입니다. 5초마다 갱신되며 300ms 이상이면 점이 노란색으로 바뀝니다. 계속 노랗다면 와이파이 신호를 확인하세요. |
| 화면 위에 **"연결 끊김"**이 빨갛게 표시됨 | 와이파이·Tailscale 연결을 확인합니다. 연결이 돌아오면 자동으로 다시 연결되고, 최신 주문을 전부 다시 받아옵니다. |
| 주문 전송 중 "전송 실패" | 연결이 돌아온 뒤 **주문 전송**을 다시 누릅니다. 같은 주문이 두 번 들어가지 않습니다. |
| 알림음이 안 울림 / 작음 | 기기 미디어 음량을 최대로 올리고, 무음 모드(아이폰·아이패드는 옆면 무음 스위치)를 끕니다. 화면 위의 종 모양 버튼이 켜져 있는지 확인하고, 페이지를 새로 고쳤다면 **시작하기**를 다시 누릅니다. 주방이 시끄럽다면 블루투스 스피커를 연결하는 것도 방법입니다. |
| 잘못 들어간 주문 | 관리자 화면 → 주문 목록 → **주문 취소**. 주방 화면에서도 바로 사라집니다. |
| 메뉴 재료 소진 | 관리자 화면 → **품절 처리**. 주문 화면에서 해당 메뉴를 선택할 수 없게 됩니다. |
| 서버가 꺼졌다 켜짐 | 주문은 `data/state.json`에 저장되므로 그대로 남아 있습니다. `npm start`로 다시 켜면 됩니다. |

## 개발

```bash
npm test     # 테스트 실행
```

- `server.js`: HTTP 서버, API, 실시간 전송(Server-Sent Events)
- `lib/store.js`: 주문 저장, 주방별 주문표 분리, 상태 변경
- `public/`: 각 화면 (빌드 과정 없는 HTML/JS)
- `public/icons.js`: 화면에서 쓰는 [Lucide](https://lucide.dev) 아이콘만 모은 파일입니다. 인터넷 없이도 아이콘이 보이도록 저장소에 포함했습니다.
  아이콘을 추가하려면 `scripts/build-icons.js`의 목록에 이름을 넣고 `npm install && npm run build:icons`를 실행합니다.
  서버 실행에는 `npm install`이 필요 없습니다.
